# 页面过渡、简介来源与主题按钮修正

## 范围与责任

Task + 发布 Operation；S2 / QA-L3；M7（已发布站点的回归修复），目标 M8（验证后发布）。Owner：Joker-of-Gotham；DRI：Codex。用户明确授权修正、验证后 add / commit / push main。范围涉及共享阅读外壳、所有文章简介和主题按钮；不增加新资产、外部数据或权限。不需要独立 RFC、隐私或安全专项评审；实现决策与回归证据记录在本文，复核依据为静态检查、自动化测试和真实浏览器截图。

## 原因与决策

- 场景固定容器使用 `#142d3b`，与当前阅读背景不同；场景、遮罩、正文被拆成多个 View Transition 快照，场景又跨路由保留。取消这些独立快照，让场景与正文在同一页面快照中合成，保留底层 canvas 的 DOM / GPU 复用。背景改为当前主题变量；根页面在 240ms 内交叉渐变，旧页面保持覆盖直到新页面显现，不做长文整体平移或缩放。导航保持稳定的独立过渡，减少动态偏好下无过渡动画。
- `renderPreview` 曾根据裸 CR 或未闭合 Markdown 分隔符，将已有 `summary` 替换成正文；为空时也截取正文。现在仅接受题头简介，不提供正文参数。各板块与搜索共用相同解析结果；简介为空则不展示。原始 YAML 中已有的截断片段保持原文，不猜测补写内容。
- 代码增强曾遍历页面所有 `pre`，可能向列表预览插入语言标签和复制按钮。现在仅增强 `.content pre` 正文代码，避免列表出现额外控件和无关扫描。
- 顶栏主题按钮使用内联 SVG 太阳 / 月亮图标，图标表示可切换的目标主题，保留当前主题说明、目标主题 tooltip、键盘操作与至少 44px 触控区域。图标遵循根主题，避免脚本初始化前出现错误文字状态。
