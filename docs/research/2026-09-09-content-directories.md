# 递归内容目录

## 决策

用户要求从扁平文件和重复题头改为递归目录写作，同时保持既有列表、卡片和正文样式。工作对象为内容结构重构，S2（涉及既有文章路径和索引）、QA-L3（内容迁移、路由契约、浏览器回归），本地验证目标 M3；Owner：Joker-of-Gotham，DRI：Codex。本记录作为范围内架构决定与迁移依据，无新增服务或外部数据处理，无需单独 RFC。

- `index.md` 是当前目录的导读；普通 Markdown 是该目录的内容。每一层都可继续包含目录，不设置业务层数上限。
- 研究目录自动形成专题路径；论文原始资料以 `kind: reference` 与札记同目录存放。
- 阅读目录里的书籍 `index.md` 使用 `kind: book`，其下独立书评自动关联这本书；普通上级目录为题材导读。博客中的书評仍通过 `books` 关联，原文只有一份。
- 最近祖先的默认信息供子文件继承，跨方向/书籍关联可以显式补充。目录草稿不公开其子树，避免因省略逐篇题头而意外公开。
- 博客、杂谈保持既有汇总列表。各级目录导读复用现有内容组件，在所属目录页开头显示；目录入口通过文章所属目录及父子导航发现。
- 已发布文章显式 slug 保持稳定。新文章未填写 slug 时使用完整相对路径，正文路由改为 rest 参数以支持任意层级。重复公开地址在构建中报错。

## 迁移与验证

迁移前搜索索引已保存到忽略的 `artifacts/content-tree/before-search-index.json`，用于比较旧文章、书籍、专题及论文 URL 和关联。最终结果在验证后补充。

## 已完成的组织调整

- 迁移 57 个 Markdown，另将四个正文路由改为 `[...slug].astro`。57 个文件的正文在统一换行后逐项比较无差异，原有显式 slug 全部保留。
- 研究按三条方向及各级问题组织，五份论文资料与相应札记共处专题目录；不再维护独立的 `papers/` 根集合。
- 五本书的资料迁入 `reading/题材/书名/index.md`，独立书评归入书内子目录；不再维护独立的 `books/` 根集合。
- 博客按图论导论、本体论、量化交易、特征工程、强化学习、前端开发、数据工程等继续细分。九篇书籍博客的共同书名移到系列导读中，正文依然保留博客唯一地址。
- 目录导读在对应页面开头渲染，子目录与文章复用现有组件。原有主列表布局、论文卡片和书架不替换成文件浏览器。文章与书籍增加所属目录链接，以便到达各层导读。
- 提供 `npm run test:content`：自动建立临时写作目录，执行真实构建验证，清理临时文件并恢复正式构建；日常写作不需要执行它。
- 启动时检查重复文件/slug，包括 Astro 加载器可能将导读和同名文章互相覆盖的情况；错误会指出对应文件。校验使用与 Astro 一致的 slug 标准化，不新增浏览器依赖。
