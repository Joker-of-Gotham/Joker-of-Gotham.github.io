# 简介仅保留行内 Markdown

Task + 发布 Operation；S2 / QA-L3；M7 → 验证后发布 M8。Owner：Joker-of-Gotham；DRI：Codex。用户授权修正简介、验证并提交推送 main。范围是共享简介解析器、简介样式及对应测试和撰写说明；不改写题头和正文。无新增外部资产或权限，无需独立 RFC 或安全专项评审；本记录保存实现决策与发布验证。

## 决策

- 在 Markdown AST 中仅保留文字与行内节点；加粗、斜体、删除线、行内代码和行内公式继续渲染，链接转换成文字。标题、列表、引用、段落中的文字合并为单段简介。
- 表格、图片及引用、HTML、代码块、行间公式整块跳过；不消耗 360 字的预览预算。纯块级简介显示为空，不回退正文。
- 对未被解析成格式节点的文本清理截断标记；跳过未闭合图片、HTML、公式片段，保留可读文字。处理 GFM 自动链接拆分不完整图片 / 链接的情况；不会猜测缺失内容。
- 先完成语法解析和过滤，再截短普通文字；行内代码和完整公式作为整体。KaTeX 的错误源码输出也被过滤，避免 RAW 残留。
- 保留作者主动转义的符号、常见金额和变量下划线。将既有解析器依赖 `micromark-util-decode-string@2.0.1` 声明为直接依赖，用于遵循 Markdown 的转义及字符实体规则；没有升级依赖版本。
- 移除简介的块级样式和无用代码高亮流程。正文仍用原来的完整 Markdown 渲染。
